# tarkov-simulator

Escape from Tarkov 시즌 1 KORD BREACH의 특성 포인트 시뮬레이터입니다. 게임에서는 특성을 모디파이어라고 부릅니다. Project Zomboid처럼 긍정 특성은 포인트를 쓰고 부정 특성은 포인트를 얻는 방식이라, 시즌이 시작하기 전에 원하는 빌드를 미리 짜 볼 수 있습니다.

## 기능

- 글로벌 모디파이어 6종은 참고용으로 표시하고, 긍정 17종과 부정 13종은 카드를 눌러 선택하거나 해제
- 긍정 소모, 부정 획득, 순합계 포인트 실시간 계산
- 같은 스탯을 정반대로 미는 특성 7쌍은 동시에 고를 수 없음. 이 충돌 목록은 공식 정보가 없어 추정한 것
- 선택 전체 초기화

## 동작 방식

클라이언트 컴포넌트 하나로 된 단일 페이지입니다. 특성 데이터는 `src/data/traits.ts`에 직접 적혀 있고 외부 API나 DB를 쓰지 않습니다. 데이터 출처는 `docs/KORDBREACH.md`이고, 수치는 시즌 시작 전에 바뀔 수 있습니다.

## 실행

의존성을 설치한 뒤 개발 서버를 띄웁니다. 환경변수는 필요 없습니다.

```bash
pnpm install
pnpm dev
```

`http://localhost:3000`에서 확인합니다. 프로덕션 빌드는 다음과 같습니다.

```bash
pnpm build
pnpm start
```
